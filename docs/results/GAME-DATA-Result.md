- **管道修复**：`_sanitize_character` 与 `/api/inventory` 的材料键过滤从"仅体力本目标"扩为全量目录（extra 材料/BOSS 掉落此前会被静默丢弃——阶段14新用例暴露）

## 附录：下拉列表修复（用户反馈，2026-10-27）

用户报告"下拉列表显示错误"。定位到两处：

1. **『按目录导入角色』下拉为空**：前端读取 `BOOT.state.game_characters`，但 bootstrap 把该字段放在响应顶层（`BOOT.game_characters`）→ 下拉无数据。已修正读取路径。
2. **导入全库污染角色库**：库名单生成时给未上线角色加"（未上线）"后缀并灌进角色库——下拉出现脏名字，选中会存成带后缀的角色名。已改为：**角色库只收 25 名已实装角色的干净名**（未上线角色仅在『按目录导入角色』下拉带标记展示）；合并导入时顺手清洗旧数据残留的后缀。

门禁：38/38 + 10/10；dist 已重建（双变体实跑 ✅）。用户需重启面板/EXE 生效，并**重新点一次『导入全库』**以清洗已导入的后缀名。
